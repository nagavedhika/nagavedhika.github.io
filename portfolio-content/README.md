# ProtoSem Obsidian Vault

This folder is the single source of truth for the ProtoSem section of the portfolio.

## Daily workflow
1. Open this folder as an Obsidian vault.
2. Open the current `Week_XX/<day>` folder.
3. Create/edit a Markdown note.
4. Paste screenshots directly into the note/folder.
5. Sync/push the repository. GitHub Actions compiles the content automatically.

### Supported images
PNG, JPG/JPEG, GIF, WEBP, SVG and AVIF.

### Suggested note structure
# Day title

## What I worked on
...

...
